# Swasthya Saarthi AI
PHP + MySQL educational triage-support prototype.

## Setup
1. Start Apache and MySQL in XAMPP.
2. Copy `Swasthya_Saarthi_PHP` to `xampp/htdocs/`.
3. Import `database/swasthya_saarthi.sql` in phpMyAdmin.
4. Open `http://localhost/Swasthya_Saarthi_PHP/`.
